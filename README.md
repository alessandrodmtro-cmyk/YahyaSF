# YahyaSF

واجهة مشاهدة عربية مستقلة. ملفات الفيديو وخادم البث المحلي لا تُرفع إلى هذا المستودع.

## نشر الموقع
تُستخدم GitHub Pages لواجهة HTML/CSS/JavaScript فقط. خادم الفيديو يعمل على جهاز المالك، ويُربط لاحقاً عبر HTTPS Tunnel.

## خصوصية وأمان
لا ترفع ملفات MP4 أو MKV أو مفاتيح أو كلمات مرور إلى GitHub.
